# Jarvis Personal Assistant 0.1.0-rc1

Data candidata: 22 ottobre 2026.

## Perimetro installabile

- backend FastAPI stateless per PostgreSQL 17 e RustFS S3-compatible;
- autenticazione multiutente, sessioni revocabili, ruoli e isolamento per nucleo;
- originali privati con hash, download autorizzato e cancellazione coordinata;
- analisi documentale strutturata con fonti, scadenze, suggerimenti e dati mancanti;
- attività Oggi con priorità, creazione e completamento;
- app Android nativa con sessione cifrata, caricamento/analisi documenti e conferma delle azioni;
- Compose di produzione compatibile con Traefik e le reti `proxy` e `jarvis-app`;
- migrazioni esplicite fino a `20261022_0006` e rollback applicativo tramite digest immutabile.

## Evidenze di verifica

- Ruff, formattazione e compilazione Python superati;
- 21 test automatici superati, un test d'integrazione opzionale escluso dalla suite ordinaria;
- migrazioni applicate su PostgreSQL 17.11 reale;
- percorso end-to-end superato con PostgreSQL, RustFS e simulatore locale della Responses API;
- cancellazione verificata: zero documenti e zero analisi residue dopo il test;
- build e lint Android superati con SDK 36 e Gradle 9.6;
- APK debug firmato con APK Signature Scheme v2;
- SHA-256 APK: `462D3EC0743FC8EF2735A84CABE07D29325280C21294C4671843F30C92D06654`.

## Prerequisiti prima del rilascio

1. creare e proteggere `/opt/jarvis/secrets/openai-api-key` sul nodo Jarvis;
2. confermare che l'account API possa usare il modello configurato e definire un limite di spesa;
3. promuovere `develop` a `main` soltanto dopo approvazione esplicita;
4. attendere il quality gate e la pubblicazione dell'immagine GHCR da `main`;
5. rendere leggibile il pacchetto GHCR al nodo o configurare un token read-only;
6. installare tramite digest, migrare, creare il primo proprietario e svolgere lo smoke test reale.

## Fuori dal perimetro v0.1

Chat libera, voce, email, calendario, notifiche, biometria, pagamenti, pratiche complete e OCR
locale sono incrementi successivi. Nessun invio, pagamento, firma o prenotazione è automatizzato.
